## 1. 変更内容

- 新しい帳票版 `DAILY_REPORT_V2`（`apps/worker/templates/daily-report-v2.html`、A4 縦1枚）を追加し、**新しく確定する作業日報は V2 で作成**する
- G4 の仮様式 `DAILY_REPORT_V1` で作成済みの帳票は版を固定したまま残す（再出力も作成時の版。帳票・メール定義書「生成時 version 固定」）
- 様式（現行帳票と同じ並び）:

| 欄 | 値 |
|---|---|
| 宛名 | お客様名「御中」、担当者「◯◯ 様」（品番の日報担当＝お客様担当者マスタ。未登録は空欄） |
| 発行元 | 三成興業株式会社、TEL・FAX・E-mail（現行帳票の記載） |
| 依頼元 / 担当者 | お客様名 / 担当者 |
| 作業日 / 運搬日 | 和暦「令和 8 年 6 月 2 日（火）」/ 空欄（運搬は別報告） |
| 作業場所 / 使用車 | マスタの名称（未選択は空欄） |
| 現地作業時間及び作業者名 | 作業者ごとに「［氏名］ 9時30分 〜 11時25分（1.92 H）」「昼休憩 0.00 H」。最低10行（空行は罫線のみ） |
| 作業内容 | 作業内容マスタの名称 |
| 品番 / ロットNo / 作業数量 / 不良個数 / 内訳 | 品番（品名）、ロット、数量、不良合計、品番の不良種別すべてと個数（0 は空欄、不良なしは「不具合なし」） |
| 計 | 作業数量・不良個数 |
| 総時間数 | 作業者数×時間（人×時間、小数2桁） |
| 運搬費 | 空欄（自動計算しない。提案書の対象外） |
| 押印欄 | 実施先担当者 / 三成担当者 / 結果報告済欄（空欄） |
| 下部 | 備考、報告番号（版）、確定日時 |

- マスタ管理のメニューに「お客様担当者」（customer_contacts）を表示する（帳票の担当者欄に使うため。メール送信は停止中のまま。CHG-004 の Blind から外す）

## 2. 検証

- domain: 和暦（令和元年・平成）、時間・時刻表記、V2 の必須 placeholder、日報ファイル名
- worker integration: 新規確定は `DAILY_REPORT_V2`、和暦・作業者行・担当者・作業場所・使用車・内訳・総時間数・備考、HTML エスケープ、作業者欄10行、未置換 placeholder なし
- 実 Chromium で A4 1ページに収まることを目視確認（サンプル PDF）
