## 2. 現行の仕様・実装との差

| 項目 | 現行（要件定義書 1.1、main fae09e1） | 変更後 |
|---|---|---|
| 作業者と時間 | 作業者を複数選び（workerIds）、開始・終了は報告に1組（startAt／endAt） | **作業者ごとの従事行**（作業者・区分・開始・終了・休憩・うち時間外）。途中参加・途中退勤・中抜けは行で表す |
| ISO 区分 | なし | 従事行ごとに「検査」「検査外」を記録（必須） |
| 工程（仕上げ・検査） | なし | 品番の設定で「仕上げ・検査」に分ける品番は、従事行に工程を記録し、数量を工程ごとに入力（設定した品番だけ） |
| 休憩 | 12:00〜13:00 と重なる時間を自動で差し引く（computeBusinessTime） | 従事行ごとに手入力（分）。自動計算は目安の表示だけ |
| 時間外 | 平日17時以降・土日・休日マスタの日を自動で時間外（参考値） | 従事行ごとに手入力（うち時間外）。**請求するかどうかは報告ごとに事務所が指定**（初期値: しない） |
| 入力の時点 | 作業終了後にまとめて入力。端末の下書きは sessionStorage、サーバーへは最後の STEP で作成と確定を続けて行う | 作業開始時に**サーバーに「作業中の日報」**を作り、どの端末からも従事行を追記できる。終わってからまとめて入力することもできる |
| 総作業時間 | 実作業時間 × 作業者数 | 全従事行の実作業時間の合計 |
| 請求単価（本番では無効の請求機能） | 品番＋作業内容（任意）＋適用日で1件 | 品番＋作業内容（任意）＋**工程（仕上げ／検査／なし）**＋適用日で1件。ISO 区分は単価に使わない |

## 3. 変更後の仕様

### 3.1 用語

| 用語 | 意味 |
|---|---|
| 従事行 | 作業日報の中の「1人の作業者が、1つの区分で、続けて作業した時間」1行。紙の「現地作業時間及び作業者名」欄の1行にあたる |
| ISO 区分 | 検査／検査外。ISO の記録のための区分で、請求には使わない |
| 工程 | 仕上げ／検査。ビナン様の一部の品番で、請求単価と数量を分けるための区分。品番マスタで「工程あり」とした品番だけに使う |
| 作業中の日報 | 作業を開始して、まだ終了していない従事行がある下書き |

### 3.2 従事行 — R-1・R-2・R-4

| 項目 | 必須 | 規則 |
|---|---|---|
| 作業者 | ○ | 有効な作業者マスタ。同じ作業者を複数行に入れてよい（中抜け・区分の切替え）。同じ作業者の行どうしで時間が重なってはいけない |
| ISO 区分 | ○ | 検査（INSPECTION）／検査外（NON_INSPECTION）。初期値は作業内容マスタの「既定の ISO 区分」。工程ありの品番では工程から決める（仕上げ→検査外、検査→検査。確認 N-2） |
| 工程 | 工程ありの品番のとき ○ | 仕上げ（FINISH）／検査（INSPECT） |
| 開始時刻 | ○ | 作業日の時刻、5分刻み |
| 終了時刻 | 確定時 ○ | 5分刻み、開始より後、翌日0:00まで。作業中（下書き）は空欄を許す |
| 休憩（分） | ○ | 0〜（終了−開始）、5分刻み。初期値0。昼休憩以外の休憩も合計して入れる |
| うち時間外（分） | ○ | 0〜行の実作業時間、5分刻み。初期値0 |

| 計算（分の整数で計算し、表示のときに時間（小数2けた）へ換算） | 式 |
|---|---|
| 行の実作業時間 | 終了 − 開始 − 休憩 |
| 総作業時間（総時間数） | 全行の実作業時間の合計 |
| 検査時間・検査外時間 | ISO 区分ごとの実作業時間の合計 |
| 仕上げ時間・検査時間（工程） | 工程ごとの実作業時間の合計（工程ありの品番のみ） |
| 時間外時間 | 全行の「うち時間外」の合計 |
| 作業時間帯（参考表示） | 最も早い開始〜最も遅い終了 |

- 行は1件に1〜100行（現行の「作業者1〜50名」を置き換える）。
- 現行の「総作業時間＝実作業時間×作業者数」は廃止する。

### 3.3 目安の表示（自動では入れない）— R-4

| 目安 | 表示する条件 | 操作 |
|---|---|---|
| 休憩 | 行が 12:00〜13:00 と重なり、休憩が0分 | 「昼の休憩が0分です（目安 60分）」と表示。「目安を入れる」で重なりの分を入れる。確定は止めない |
| 時間外 | 平日の17:00以降、または土日・休日マスタの日の作業 | 「時間外の目安 ○.○○H」を表示。「目安を入れる」で入れる。確定は止めない |

休日マスタは、この目安と「休日」の表示にだけ使う（時間の計算には使わない）。

### 3.4 作業中の追記（途中参加・途中退勤）— R-1

| 操作 | 画面の動き | サーバー |
|---|---|---|
| 作業を開始 | STEP1〜2（お客様・品番・作業内容）の後、STEP3 で開始した作業者を選び「開始」。開始時刻は現在時刻を近い方の5分に丸めた値（修正可） | 作業日報の下書きを作成（報告番号を採番）。従事行を追加 |
| 途中参加 | 「作業者を追加」→ 作業者（・工程）を選び「開始」 | 従事行を追加 |
| 退勤・作業終了 | 行の「終了」→ 終了時刻（丸め・修正可）。休憩・時間外を入力 | 従事行を更新 |
| 区分・工程の切替え、中抜け | 行を終了し、同じ作業者で行を追加 | 終了と追加 |
| 間違えた行 | 「行を取り消す」（下書きの間だけ） | 従事行を削除（変更の記録に残る） |
| まとめて入力 | 作業後に行を追加し、開始・終了を手で入れる（現行に近い使い方） | 同上 |
| 確定 | 全行に終了時刻がないと STEP4 へ進めない。STEP4（数量・不良）→ STEP5（確認）→ 確定 | 確定時に全行を検証し、合計を計算して保存 |

- 現場ホームに「作業中の日報」（終了していない行がある下書き）を表示する。**どの現場の利用者の端末からも**開いて行を追加・終了できる（確認 2-5 当方案）。作業日・お客様・品番・作業内容など行以外の項目と確定は、報告者本人と事務所だけが行える（現行の canWrite と同じ）。
- 行の追加・終了・修正は行ごとの操作（別の端末で同時に操作しても、他の行を上書きしない）。報告全体の更新は従来どおり expectedVersion で同時更新を防ぐ。
- 「作業中」の日報は通信できる状態で操作する。通信が切れているときは時刻を控え、戻ってから入力する（後から直せる）。
- 作業中の日報は24時間で消えない（サーバーに保存）。誤って作った下書きは、報告者本人と事務所が「破棄」できる（一度も確定していない報告だけ。状態 DISCARDED、一覧・集計の対象外、記録は残す）。

### 3.5 ISO 区分 — R-2・A-1

- ISO 区分は従事行の必須項目。作業内容マスタに「既定の ISO 区分」を追加し、行の初期値にする（初期データの案: 成形補正・塗装手直しは検査外、それ以外の検査・確認・計測・測定は検査。確認 N-5）。
- 作業結果報告書には行ごとに【検査】または【検査外】を印字する（紙の【検査・検査外】欄で、選んだ方）。工程ありの品番は【仕上げ】【検査】を印字する（ビナン様の社内用日報の欄と同じ言葉）。
- 月次集計に「作業者別」のシートを追加し、作業者×ISO 区分の時間を出す（確認 2-11 当方案）。

### 3.6 工程別の数量 — R-3・A-1・A-2

| 項目 | 内容 |
|---|---|
| 品番マスタの設定 | 「工程」: なし（ISO 区分だけ）／仕上げ・検査。「工程ごとに数量を入れる」: はい／いいえ（工程が仕上げ・検査のときだけ） |
| 初期データ | 品番一覧で「仕上げ・検査」の品番（ビナン様 10品番）は工程「仕上げ・検査」。そのうち請求書で仕上げ・検査を分けている MB504237・A8202415600・8-970363420 を「工程ごとに数量を入れる: はい」（確認 N-1） |
| 入力（STEP4） | 「工程ごとに数量を入れる」品番は「仕上げ数量」「検査数量」を入力（どちらも 0〜999,999。同じ日に両方行えば両方入れる）。それ以外は従来どおり作業数量1つ |
| 不良の合計 | 工程ごとの品番は、仕上げ数量と検査数量の大きい方以下 |
| 処理数量（一覧・月次の作業個数） | 工程ごとの品番は仕上げ数量＋検査数量（延べ個数。請求書の数量の合計と一致） |
| 帳票 | 作業数量の欄に「仕上げ 454／検査 0」のように印字 |

### 3.7 時間外の請求の指定 — R-4（確認 2-9・2-10 当方案）

- 現場は従事行に「うち時間外」を入れる（目安を参考に）。事務所は報告の確認時に直せる（修正＝新しい版）。
- 「時間外を請求する」は報告ごとの指定で、**事務所が報告の詳細画面で後から指定**する（運搬費の後入力と同じく、版は作らず変更の記録を残す）。初期値は「しない」。
- 「しない」のときも、うち時間外の時間は記録として残る。月次集計では通常の時間として数える。

### 3.8 月次集計・出力

| 追加・変更 | 内容 |
|---|---|
| 集計の値 | 総作業時間（行の合計）、検査時間、検査外時間、時間外時間（請求する／しない）、割増作業時間（＝請求する時間外）、通常作業時間（＝総作業時間−割増作業時間）、休憩時間 |
| 作業内容別 | 品番×作業内容×工程ごとの件数・数量・不良・時間 |
| 作業者別（新しいシート） | 作業者×ISO 区分（×工程）ごとの時間・日数（ISO の記録用） |
| 品番日別（新しいシート。CHG-017 と共通） | 品番×日ごとの有無・数量（工程ごと）・不良・通常作業時間・割増作業時間・作業時間・移動回数（事務所用の集計表と同じ並び） |
| 明細 | 報告ごとの総作業時間・検査・検査外・時間外・時間外を請求するか |
| 廃止 | 「実作業時間（報告単位）」の値（行ごとの時間に置き換えるため）。画面の「実作業時間」は「総作業時間」に統一 |

Excel は 集計・日別・品番別・作業内容別・作業者別・品番日別・明細 の7シートになる。

### 3.9 本番データ・旧形式

- 旧形式（schemaVersion 1: workerIds×開始・終了）の版は読み取り専用で残し、画面・帳票（V1・V2）は旧形式で表示する。
- 旧形式の報告を修正するときは、作業者ごとに同じ開始・終了・休憩の従事行を作って新形式の下書きにする（ISO 区分は作業内容の既定値、時間外は旧版の時間外を作業者数で割って各行へ。割り切れない分は最初の行）。
- 本番には業務データが登録されていない想定（10/16 時点）。切替えの前に Firestore で workReports の件数を確認し、0件でなければこの変換を使う。開発の試験データは手順書 08 の後片付け → 新形式で作り直す。

## 4. データの変更（詳細設計書 2.3・2.4）

### 4.1 workReports/{id}/revisions（作業日報の版、schemaVersion 2）

workReports に（inProgress, businessDate 降順, createdAt 降順）を追加（現場ホームの作業中の日報）。索引は workReports 6件・deliveryReports 5件の計11件になる。

エラーコード（fields の code）: labor_overlap（同じ作業者の時間の重なり）、labor_open（終了していない行）、break_exceeds（休憩が行の時間以上）、overtime_exceeds（時間外が行の実作業時間を超える）、stage_required（工程ありの品番で工程がない）、labor_lines_range（1〜100行）。

## 8. 帳票（DAILY_REPORT_V3）

- 従事行ごとに「〔氏名〕【検査】 9時30分〜11時25分（1.92H） 休憩 0.00H」を印字。最低10行、11行目以降は次の頁に続ける。
- 総時間数は全行の実作業時間の合計。
- 「時間外を請求する」は帳票に載せない（社内の判断のため）。
- 品番・数量の欄は CHG-017 の明細（品番・ロットの行）。
- 新しく確定する作業日報は V3 で作る。V1・V2 で作成済みの帳票は、再出力も作成時の様式（現行どおり）。
