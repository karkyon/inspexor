## 2.2 主な確認内容

| 区分 | 確認内容 |
|---|---|
| 時間の計算 | 休憩（12:00〜13:00 の重なり）、実作業時間・総作業時間、5分刻み、日をまたぐ入力の拒否、提案書 P.9 の例（9:30〜11:25・2名 → 1.92H／3.83H） |
| 入力の規則 | 必須項目、数量の範囲、不良合計≦数量、作業者の重複・上限、運搬明細の品番重複、ロット必須の品番、無効なマスタの拒否 |
| 確定 | 報告番号の採番、二重押し・再送で二重登録しないこと、確定後は現場で変更できないこと |
| 版 | 修正で新しい版ができ、前の版と PDF が残ること、修正中も月次集計は前の確定版で数えること |
| 同時更新 | 他の人の更新後に保存すると止まること |
| 帳票 | 様式の全欄の値、不良なしの「不具合なし」、作業者欄10行、文字の無害化、作成時の様式で再出力すること、失敗時のやり直し |
| 集計 | 日別・品番別・作業内容別・明細の値、品番指定時の運搬数量、運搬費の合計と未入力件数、Excel 5シート、CSV の文字コードと数式の無害化 |
| 権限 | 区分ごとに許可された操作だけができること、現場の利用者が他人の報告を見られないこと、権限のない操作の記録 |
| セキュリティ | ログインのロック、ログイン状態の期限、CSRF トークンのない要求の拒否、PDF リンクの期限・改ざんの拒否 |
| 通信切れ | 下書きの継続、確定ボタンの無効化、復帰後の確定 |
