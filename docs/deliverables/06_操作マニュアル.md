# 1. はじめに

## 1.1 このマニュアルについて

SANSEI 現場報告システムの使い方を説明します。

- 第2章: 全員共通（ログイン・ログアウト）
- 第3章: 現場 iPad 編（作業日報・運搬実績の登録、日報PDFの送付）
- 第4章: 事務所 管理画面編（報告の確認・修正・再出力・運搬費、月次集計、マスタ管理）
- 第5章: 困ったときは

## 1.2 使う前に

| 項目 | 内容 |
|---|---|
| 接続先 | お渡しする URL（https://〜.run.app）。iPad はホーム画面に追加しておくと便利です（Safari の共有ボタン →「ホーム画面に追加」） |
| 端末 | 現場: iPad（Safari）。事務所: パソコン（Chrome または Edge） |
| アカウント | ログインIDとパスワードをお一人ずつお渡しします。他の方と共有しないでください |
| 通信 | インターネットにつながる場所で使います。通信が切れても入力途中の内容は消えません |

# 2. 全員共通

## 2.1 ログイン

1. 接続先の URL を開きます。ログイン画面が表示されます。
2. 「ログインID」と「パスワード」を入力し、「ログイン」を押します。
3. ホーム画面が表示されます。表示される入口は、利用者の区分によって異なります。

| 区分 | ホームに表示される入口 |
|---|---|
| 現場 | 現場入力へ |
| 事務所 | 現場入力へ、報告一覧へ、月次集計へ、マスター管理へ |
| 管理者 | 現場入力へ（閲覧のみ）、報告一覧へ、月次集計へ、マスター管理へ |
| 監査 | 報告一覧へ、月次集計へ、マスター管理へ（すべて参照のみ） |

- パスワードを5回続けて間違えると、15分間ログインできません。時間をおいてやり直すか、管理者に連絡してください。
- 短い時間に何度もログインを試すと「しばらく時間をおいてから再度お試しください」と表示されます。数分待ってからやり直してください。
- 画面上部の名前の横に、区分（現場・事務所・管理者・監査）が表示されます。
- しばらくぶりに開いたときは、最初の表示に数秒かかることがあります。

## 2.2 ログアウト

画面上部の「ログアウト」を押します。iPad を他の人と共用する場合は、使い終わったら必ずログアウトしてください。

- 操作しないまま30分たつか、ログインから12時間たつと自動でログアウトします。
- ログアウトすると、その端末の下書きは消えます。

# 3. 現場 iPad 編

## 3.1 現場ホーム

「現場入力へ」を押すと現場ホームが表示されます。

| 表示 | 内容 |
|---|---|
| 作業日報を登録 | 検品・加工・選別の実績を登録します（3.2） |
| 作業中の日報 | 作業を開始して、まだ終わっていない作業者がいる作業日報です。どなたが開始したものも表示されます。「続きを入力」で作業者の追加・終了ができます（3.2 STEP 3） |
| 運搬実績を登録 | 集荷・納品した品番と数量を登録します（3.3） |
| この端末の下書き | 入力途中の報告があると「作業日報の下書きを再開」「運搬実績の下書きを再開」が表示されます |
| 最近の登録 | 自分が登録した報告と、日報PDFの状態（作成中・作成済）が表示されます |

## 3.2 作業日報を登録する

作業を始めるときに作業日報を開始し、作業者が加わったとき・帰ったときに追記します。作業が終わってからまとめて入力することもできます。5つの段階で入力し、画面上部に「STEP 1/5」のように現在の段階が表示されます。

### STEP 1 日付・報告者・お客様

1. 「作業日」を確認します（今日が入っています）。別の日はカレンダーから選びます。
2. 「報告者」にはログインした本人の名前が入っています（事務所の方が現場の方の代わりに入力する場合は 4.10）。
3. 「お客様」を選びます。
4. 「作業場所」を選びます（任意）。
5. 「次へ進む」を押します。

### STEP 2 品番・作業内容

1. 「品番」を選びます。選んだお客様の品番だけが表示されます。品名も表示されます。
2. 「作業内容」を選びます。選んだ品番の作業内容だけが表示されます。作業場所が決まっている作業内容は、作業場所が自動で入ります。
3. 「ロットNo」を入力します。品番によっては入力が必須です。
4. 1枚の報告に複数の品番があるとき、または同じ品番でロットごとに数量を分けるときは、「＋ 品番・ロットを追加」で行を増やし、1〜3 を繰り返します（時間で請求する品番は1件に1品番です）。
5. 作業場所がお客様の工場のときは「移動回数」を入力します。
6. 「使用車」を選びます（任意）。
7. 「次へ進む」を押します。

### STEP 3 作業者・作業時間

作業者ごとに1行ずつ入力します。

1. 「＋ 作業者を追加」を押し、作業者を選びます。
2. 「区分」を確認します（検査／検査外。仕上げ・検査の品番では仕上げ／検査）。初期値は作業内容で決まっています。違えば選び直します。
3. 作業を始めるときに「開始」を押します（現在時刻が5分単位で入ります。手で直せます）。この時点で作業日報がクラウドに保存され、現場ホームの「作業中の日報」に表示されます。
4. 途中から加わる方がいれば、1〜3 で行を追加します。別の方の iPad からも、現場ホームの「作業中の日報」→「続きを入力」で追加できます。
5. 帰る方・作業を終えた方は、その行の「終了」を押します。
6. 行ごとに「休憩（分）」と「うち時間外（分）」を入れます。昼休憩以外の休憩も合計して入れます。休憩がなければ 0 のままです。
   - 昼（12時〜13時）にかかる行で休憩が0分のとき、「昼の休憩が0分です」と表示されます。「目安を入れる」を押すと入ります。
   - 17時以降・土日・休日の作業には「時間外の目安」が表示されます。「目安を入れる」を押すと入ります。時間外を請求するかどうかは事務所が決めます。
7. 同じ方が途中で抜けて戻ったとき、午前と午後で区分が変わるときは、行を終了してから同じ方の行を追加します。
8. 間違えて追加した行は「行を取り消す」で消せます。
9. 全員の行に終了時刻が入ったら「次へ進む」を押します（終わっていない方がいる間は進めません）。

作業が終わってからまとめて入力するときは、1・2 の後に開始・終了の時刻を手で入れます。総作業時間は全員の時間の合計です（例: 2名とも 9:30〜11:25 なら 1.92H×2＝3.83H）。日をまたぐ作業は入力できません。深夜0時に終わった作業は、終了を「00:00」にします。作業中の日報への追記は、通信できる場所で行ってください。

### STEP 4 数量・不良

品番・ロットの行ごとに入力します。

1. 「作業数量」を入力します。仕上げ・検査で数量を分ける品番（例: A8202415600）は、「仕上げ数量」「検査数量」にその日に行った分を入れます（行わなかった方は0）。
2. 不良があった場合は、「不良内訳」の該当する種別に個数を入力します（ない種別は空欄のまま）。「その他」に個数を入れたときは、内容（例: 色ハゲ、サンプル）も入れます。
3. 良品数量と不良率が自動で表示されます。
4. 必要なら「備考」を入力します。
5. 「内容を確認」を押します。

### STEP 5 登録内容を確認

1. 入力した内容が一覧で表示されます。違うところがあれば「← 戻る」で直します。
2. 「内容を確認しました」にチェックを入れます。
3. 「確定して登録」を押します。

確定すると報告番号（例: WR-202610-000001。作業を開始したときに付いています）が表示され、日報PDFの作成が始まります。確定後の内容は現場では変更できません。間違いに気づいたら事務所に連絡してください。

## 3.3 運搬実績を登録する

### STEP 1 運搬の基本情報

1. 「運搬日」「運転者」「お客様」を選びます。
2. 「使用車両」を選びます（任意）。
3. 「次へ進む」を押します。お客様を変えると、次の画面で選んだ品番は外れます。

### STEP 2 運搬した品番と数量

1. 品番を選び、数量を入力します。複数の品番がある場合は行を追加します。同じ品番は1行にまとめてください。
2. 「運搬回数」を入力します（初期値1）。
3. 「運搬費」は分かっていれば入力します。分からなければ空欄のまま進みます（事務所が後で入力します）。
4. 「次へ進む」を押します。

### STEP 3 登録内容を確認

内容を確認して「内容を確認しました」にチェックを入れ、「確定して登録」を押します。

## 3.4 日報PDFを確認してメールで送る

1. 確定後の画面（または現場ホームの「最近の登録」）に「日報PDFをプレビュー」「日報PDFをダウンロード」が表示されます。作成中の場合は「作成しています…」と表示されるので、少し待ちます。
2. 「日報PDFをプレビュー」を押すと、PDF が表示されます。内容を確認します。
3. 画面の共有ボタン（四角から上向きの矢印）を押し、「メール」を選びます。
4. 宛先を入力して送信します。

システムからメールは自動送信されません。これまでどおり、担当者が送ってください。

## 3.5 入力途中で中断したとき

- 入力途中の内容は iPad に自動で保存されます。現場ホームの「この端末の下書き」にある「作業日報の下書きを再開」（運搬は「運搬実績の下書きを再開」）から続きを入力できます。
- この端末の下書きは最後の保存から24時間たつか、ログアウトすると消えます。
- 作業を開始した作業日報は「作業中の日報」としてクラウドに残ります（24時間で消えません）。間違えて作った作業日報は、事務所に破棄を依頼してください（自分で作ったものは報告の詳細から破棄できます）。
- 通信が切れると画面上部に表示が出て、「確定して登録」が押せなくなります。入力は続けられます。通信が戻れば確定できます。

# 4. 事務所 管理画面編

## 4.1 画面の構成

画面左のメニューから「報告一覧」「月次集計」「マスター管理」「利用者管理」を選びます。画面の幅が狭い場合、メニューは「一覧」「集計」「マスタ」「利用者」と短く表示されます。

## 4.2 報告一覧

1. 「報告一覧」を開くと、今月の作業日報と運搬実績が日付の新しい順に表示されます。
2. 絞り込む場合は、「期間（から）」「期間（まで）」「種別」「お客様」「品番」「状態」を選びます。
3. 報告番号を押すと詳細画面が開きます。

| 状態 | 意味 |
|---|---|
| 下書き | 入力中、作業中、または修正中（「作業中」で絞り込めます） |
| 確定 | 確定済み。日報PDFの作成待ち |
| 提出済 | 日報PDFの作成済み |
| 破棄 | 間違えて作った作業日報を破棄したもの（「状態」で「破棄」を選んだときだけ表示） |

## 4.3 報告の詳細とPDF

詳細画面では、報告の全項目（作業日報は作業者ごとの行と合計、品番の行ごとの数量・不良）と、日報PDF（運搬は運搬実績報告書PDF）のプレビュー・ダウンロードができます。

### 時間外を請求するかを指定する

1. 確定した作業日報の詳細画面の「時間外を請求する」で「する」または「しない」を選びます（初期値は「しない」）。
2. 必要なら理由を入れ、「保存」を押します。

- 新しい版は作られません。誰がいつ変えたかは記録されます。
- 「しない」のときも、時間外の時間は記録に残ります。月次集計では「割増作業時間」に数えません。
- 時間外の時間そのものを直すときは、報告を修正します（4.6）。

### 下書きを破棄する

確定したことのない作業日報（間違えて開始したものなど）は、詳細画面の「下書きを破棄」で理由を入れて破棄できます。破棄した報告は一覧の初期の表示と月次集計から外れます。記録は残ります。

## 4.4 PDFを再出力する

1. 詳細画面の「再出力の理由」に理由を入力します（例: お客様から再送の依頼）。
2. 「日報PDFを再出力」を押します。
3. 少し待つと新しいPDFが表示されます。様式は最初に作成したときと同じです。

## 4.5 運搬費を入力する

1. 運搬実績の詳細画面を開きます。
2. 「運搬費の入力」に、按分等を確認した確定金額を入力します（0〜9,999,999円）。
3. 「運搬費を保存」を押します。

- 空欄で保存すると「未確定」に戻ります。
- 運搬費の変更では新しい版は作られません。誰がいつ変えたかは記録されます。

## 4.6 報告を修正する

確定済みの報告の内容を直すときは、新しい版を作ります。前の版とそのPDFは残ります。

1. 詳細画面の「修正（新しい版を作成）」で「修正理由」を入力し、「修正を始める」を押します。
2. 現場と同じ入力画面が開きます。内容を直します。
3. STEP の最後で「確定して登録」を押します。
4. 新しい版（第2版など）の日報PDFが作成されます。

- 修正中（下書き）の間、月次集計は前の確定版の内容で数えます。
- 修正中の報告は、詳細画面の「入力画面で編集する」から続きを入力できます。
- 他の人が先に更新していた場合は「他の利用者が更新しました」と表示されます。再読込してからやり直してください。

## 4.7 月次集計と Excel・CSV 出力

1. 「月次集計」を開きます。
2. 「対象年月」を選びます。必要なら「お客様」「報告種別」「品番」で絞り込みます。
3. 「集計する」を押すと、合計（総作業個数・総不良個数・総作業時間・検査時間・検査外時間・時間外時間・割増作業時間・通常作業時間・運搬数量・運搬回数・手入力運搬費）が表示されます。
4. 表を「日別」「品番別」「作業内容別」「作業者別」「品番日別」「明細」から切り替えて確認します。「作業者別」は ISO の記録（作業者ごとの検査・検査外の時間）に、「品番日別」は品番ごとの集計表（事務所用）の代わりに使えます。
5. 「Excel で出力（全シート）」を押すと、7つのシート（集計・日別・品番別・作業内容別・作業者別・品番日別・明細）の Excel ファイルが保存されます。「CSV で出力（表の名前）」は表示中の表を CSV で保存します。

- 集計の対象は確定済みの報告です。下書きは含みません。
- 運搬費は入力された金額の合計です。未入力の件数も表示されるので、月末の集計前に入力を済ませてください。
- 出力した集計は、従来の請求用 Excel への転記に使います。時間外を請求する報告は、月末の集計の前に指定を済ませてください。

## 4.8 マスタ管理（管理者）

| マスタ | 使われる場所 |
|---|---|
| お客様 | 入力時の選択、日報の宛名 |
| お客様担当者 | 日報の宛名・担当者欄（部署名、担当品番を設定） |
| 品番 | 入力時の選択（お客様ごと）。工程（なし／仕上げ・検査）と、仕上げ・検査ごとに数量を入れるか |
| 作業内容 | 入力時の選択（品番ごと）。既定の区分（検査／検査外）と既定の作業場所 |
| 不良種別 | 不良内訳の入力欄（品番ごと、表示順） |
| 作業者 | 作業者・運転者の選択 |
| 作業場所・車両 | 作業場所・使用車・使用車両の選択。作業場所には「お客様の工場」の印（日報の移動回数の欄） |
| 休日 | 時間外の目安と休日の表示（時間の計算には使いません） |

### 追加する

1. 「マスター管理」で種類を選び、「＋ ○○を追加」（例: ＋ 作業者を追加）を押します。
2. 項目を入力し、「登録する」を押します。コードが重複していると、項目の横にエラーが表示されます。

### 修正する

1. 一覧から対象を選びます。
2. 項目を直し、「変更理由」を入力して「変更を保存」を押します。

### 使わなくなったとき（無効化）

1. 対象を開き、「無効化」を押します。
2. 確認画面で理由を入力し、「無効化する」を押します。

無効にしたデータは削除されず、新しい入力の選択肢から外れます。過去の報告はそのまま残ります。一覧の「状態」で「無効のみ」を選ぶと確認できます。

事務所の区分の方はマスタを参照のみできます。追加・修正は管理者の区分が必要です。

## 4.9 利用者管理（管理者）

ログインできる人と、使える画面（区分）を管理します。

### 利用者を追加する

1. 左のメニューの「利用者管理」を開き、「利用者を追加」を押します。
2. 「ログインID」（3〜100文字の英数字と . _ @ -。後から変更できません）、「表示名」、「区分」（現場・事務所・管理者・監査）を入力します。
3. パスワードを入力するか、自動生成します（12文字以上）。
4. 保存すると、パスワードが表示されます。画面を閉じると再表示できないため、本人に安全な方法（手渡し・電話など）で伝えてください。

### 表示名・区分を変える

一覧から利用者を選び、表示名・区分を直して保存します。区分を変えた利用者は、再ログインが必要になります。

### パスワードを再設定する・ロックを解除する

- 「パスワードの再設定」で新しいパスワードを設定します。その利用者のログイン中の画面はすべてログアウトされ、ロックも解除されます。
- ログインから10分以上たっていると、操作の前に「本人確認」の画面が開きます。ご自身（管理者）のパスワードを入力して「確認」を押すと、そのまま再設定が行われます。
- パスワードを続けて間違えてロックされている利用者は「ロック中」と表示されます。ロックの解除ができます（15分たつと自動でも解除されます）。

### 利用を停止する（退職など）

「利用の停止・再開」で理由（任意。例: 退職のため）を入力して無効にします。すぐにログインできなくなります。報告などの記録は残ります。再開する場合は「有効にする」を押します。

- 自分自身は無効にできません。また、有効な管理者が0人になる変更はできません。
- 作業者マスタ（作業者・運転者として選ぶ名前）は利用者とは別です。新しい方が入ったときは、必要に応じてマスタの「作業者」にも追加してください。

## 4.10 作業日報を代理で入力する（事務所）

現場の方の iPad が故障したときなどに、事務所の方が現場の方の代わりに作業日報を入力できます。登録した日報は、選んだ現場の方の報告になります。

1. ホームの「現場入力へ」から「作業日報を登録」を開きます。
2. STEP 1 の「報告者」で「○○（ログインID）の代理で入力」を選びます。
3. 「代理入力の理由」を入力します（必須。例: 現場の方の iPad が故障のため事務所で入力）。
4. 以降は 3.2 と同じ手順で入力し、確定します。
5. ログインから10分以上たっている場合は、確定の前に「本人確認」の画面が開きます。ご自身のパスワードを入力して「確認」を押すと、そのまま登録されます。

- 登録した日報は、選んだ現場の方の現場ホーム・報告一覧に表示されます。
- 報告の詳細には「代理入力」として、入力した方・日時・理由が表示されます。
- 運搬実績は運転者を選んで入力するため、代理入力はありません。

# 5. 困ったときは

| 症状 | 対処 |
|---|---|
| ログインできない | ID・パスワードを確認してください。5回間違えると15分ロックされます。何度も試して「しばらく時間をおいてから」と表示された場合は数分待ってください。急ぐ場合や忘れた場合は、管理者が利用者管理でロック解除・パスワード再設定を行います |
| 「確定して登録」が押せない | 通信が切れていないか確認してください。「内容を確認しました」のチェックも必要です |
| STEP 3 から先へ進めない | 終了時刻が入っていない作業者がいます。全員の「終了」を押すか、時刻を入れてください |
| 「同じ作業者の時間が重なっています」 | 同じ方の行の時間が重なっています。前の行を終了してから次の行を追加してください |
| 作業中の日報が多く残っている | 確定し忘れ、または間違えて開始した日報です。続きを入力して確定するか、事務所で破棄してください |
| 入力エラーが表示される | 画面上部のエラー一覧の項目を押すと、該当箇所へ移動します。表示された理由に従って直してください |
| 「この報告は既に確定済みのため変更できません」 | 既に確定済みです。現場ホームで下書きを破棄し、内容の訂正は事務所に依頼してください |
| 日報PDFが「作成しています…」のまま | 1〜2分待って「もう一度確認」を押してください。「作成できませんでした」と出た場合は事務所に連絡してください（事務所で再出力します） |
| PDFのリンクを開くとエラーになる | リンクの有効期限（10分）が切れています。画面を開き直してください |
| 選びたいお客様・品番・作業者が出てこない | マスタに登録されていないか、無効になっています。管理者に登録を依頼してください |
| 「他の利用者が更新しました」 | 他の人が先に更新しました。画面を再読込してからやり直してください |
| 画面が表示されない | 通信を確認し、しばらく待って再読込してください。続く場合は当方へ連絡してください（運用・保守手順書の連絡先） |
