# 1. はじめに

## 1.1 本書の目的

本書は、三成興業株式会社様の「作業日報デジタル化システム（SANSEI 現場報告システム）」について、システムで行うこと・行わないこと、入力する項目、日報PDFの様式、月次集計の内容、完成を判定する基準を定め、お客様と当方の間で合意するための資料です。

本書で合意した内容が、以降の設計・開発・テスト・検収の基準になります。

# 2. システム化の目的と範囲

## 2.1 目的

現場で手書きしている作業結果報告書・運搬記録を iPad の入力に置き換え、次の作業を減らします。

- 手書きの日報作成と、日報のPDF化
- 事務所での手書き内容の確認・転記
- 日報から月次集計表への手作業での転記・集計

## 2.2 業務の流れ（導入後）

| 順 | 誰が | 何をする | システムの動き |
|---|---|---|---|
| 1 | 現場作業者 | 作業終了後に iPad で「作業日報」または「運搬実績」を入力し、確定する | クラウドに保存し、日報PDFを自動で作成 |
| 2 | 現場作業者 | 日報PDFをプレビューし、iPad の共有機能でメールに添付してお客様へ送る | （メールの自動送信はしません） |
| 3 | 事務所担当者 | 報告一覧で内容を確認し、必要なら修正（新しい版）や運搬費の入力を行う | 修正すると新しい版の日報PDFを作成 |
| 4 | 事務所担当者 | 月末に月次集計を行い、Excel または CSV で出力する | 確定済みの報告を自動で集計 |
| 5 | 事務所担当者 | 出力した集計を、従来の請求用 Excel に転記して請求書を作成する | （請求計算・請求書作成はしません） |

## 2.4 システムで行わないこと（対象外）

提案書 P.3 のとおり、次の機能は今回の範囲に含みません。

- 日報メールの自動送信（担当者が従来どおり iPad からメール添付で送ります）
- 請求書・請求書鏡の自動作成、請求金額の自動計算
- 運搬費の自動按分・単価判定、請求金額への自動反映
- 時間外 1.25 倍の請求計算、複雑な請求条件マスタ
- 承認ワークフロー、高機能ダッシュボード
- お客様担当者ごとのメール送信設定
- IC カード・バーコードによる入力、他システムとの連携

これらは将来のご要望に応じて別途お見積りします。

# 3. 利用者と権限

## 3.1 利用者の区分

| 区分 | 想定する利用者 | できること |
|---|---|---|
| 現場 | 現場作業者・運転手 | 作業日報・運搬実績の入力と確定、自分が登録した報告と日報PDFの表示 |
| 事務所 | 事務所担当者 | すべての報告の確認・修正・PDF再出力・運搬費の入力、月次集計と出力、マスタの参照、作業日報・運搬実績の入力 |
| 管理者 | 事務所の責任者 | マスタの追加・修正・無効化、利用者の管理、報告の確認・PDF再出力・運搬費の入力、月次集計と出力 |
| 監査（閲覧） | 確認のみ行う方 | 報告・月次集計の参照と出力（変更はできない） |

1人の利用者に複数の区分を設定できます。事務所でマスタも管理する方は「事務所＋管理者」とします。

## 3.2 アカウント

- 導入時のアカウント（ログインIDとパスワード）は当方が作成してお渡しします。
- 運用中は、管理者が「利用者管理」画面で利用者の追加・区分の変更・利用停止・パスワード再設定・ロック解除を行えます（当方に依頼することもできます）。
- 利用者は削除せず「利用停止」にします。過去の報告は残ります。
- 利用停止・区分の変更・パスワード再設定は、その利用者がログイン中でもすぐに反映されます。
- 管理画面で設定するパスワードは12文字以上とします。5回続けて間違えると15分間ログインできなくなります。

# 4. 機能要件

## 4.1 作業日報の入力（F-02）

### 入力項目

| 段階 | 項目 | 入力方法 | 必須 | 規則 |
|---|---|---|---|---|
| 1 基本情報 | 作業日 | カレンダーから選択（当日が初期値） | 必須 | |
| | 報告者 | ログインした本人が自動で入る | 必須 | 代理入力はしません |
| | お客様 | マスタから選択 | 必須 | |
| | 作業場所 | マスタから選択 | 任意 | |
| 2 品番・作業内容 | 品番 | 選んだお客様の品番から選択（品名も表示） | 必須 | |
| | 作業内容 | 選んだ品番の作業内容から選択 | 必須 | |
| | ロットNo | 手入力（複数はカンマ区切り） | 品番の設定による | 100文字まで。品番マスタで「ロット必須」の品番は必須 |
| | 使用車 | マスタから選択 | 任意 | |
| 3 作業者・時間 | 作業者 | マスタから複数選択 | 必須 | 1〜50名 |
| | 開始時刻・終了時刻 | 選択（5分刻み） | 必須 | 終了は開始より後。日をまたぐ作業は入力できない（終了は翌日0:00まで） |
| 4 数量・不良 | 作業数量 | 手入力 | 必須 | 0〜999,999個 |
| | 不良内訳 | 品番ごとの不良種別に個数を手入力 | 任意 | 不良の合計は作業数量以下 |
| | 備考 | 手入力 | 任意 | 500文字まで |
| 5 確認 | 入力内容の確認 | 一覧表示、「内容を確認しました」にチェックして確定 | 必須 | |

### 自動計算

| 項目 | 計算方法 |
|---|---|
| 休憩時間 | 作業時間のうち 12:00〜13:00 に重なる時間を休憩として差し引く（例: 9:30〜11:25 は0分、9:00〜15:00 は60分、12:30〜15:00 は30分） |
| 実作業時間 | 終了時刻 − 開始時刻 − 休憩時間 |
| 総作業時間 | 実作業時間 × 作業者数 |
| 不良合計 | 不良内訳の個数の合計 |
| 良品数量 | 作業数量 − 不良合計（画面の参考表示） |

例（提案書 P.9）: 9:30〜11:25、作業者2名 → 実作業時間 1.92 時間、総作業時間 3.83 時間（分で計算し、表示時に時間へ換算）。

## 4.2 運搬実績の入力（F-03）

| 段階 | 項目 | 入力方法 | 必須 | 規則 |
|---|---|---|---|---|
| 1 基本情報 | 運搬日 | カレンダーから選択（当日が初期値） | 必須 | |
| | 運転者 | 作業者マスタから選択 | 必須 | |
| | お客様 | マスタから選択 | 必須 | |
| | 使用車両 | マスタから選択 | 任意 | |
| 2 品番・数量 | 品番と数量 | 選んだお客様の品番を選び、数量を入力（複数品番可） | 必須 | 1品番以上。数量は1〜999,999個。同じ品番は1行にまとめる |
| | 運搬回数 | 手入力 | 必須 | 1〜99回（初期値1） |
| | 運搬費 | 手入力 | 任意 | 0〜9,999,999円。空欄なら「未確定」として保存し、事務所が後から入力 |
| 3 確認 | 入力内容の確認 | 一覧表示、チェックして確定 | 必須 | |

運搬費は自動計算しません。

## 4.3 確定と報告番号

- 確定すると、報告番号を自動で付けます。作業日報は `WR-年月-連番6桁`、運搬実績は `DR-年月-連番6桁`（例: WR-202610-000001）。年月は登録した日の年月です。
- 確定後、現場の利用者は内容を変更できません。変更は事務所が行います（F-07）。
- 同じ確定操作を通信の再送などで二重に行っても、報告が二重に登録されないようにします。

## 4.4 下書き（F-13）

- 入力途中の内容は iPad に自動保存されます。画面を閉じても、続きから入力できます。
- 下書きは最後の保存から24時間で消えます。ログアウトしたときも消えます。
- 通信が切れている間は画面上部に表示が出て、確定ボタンが押せなくなります。入力は続けられ、通信が戻れば確定できます。

## 4.5 日報PDF（F-04, F-05）

### 作業日報（作業結果報告書）

現行の紙の作業結果報告書と同じ並びで、A4 縦1枚に出力します。

| 欄 | 内容 |
|---|---|
| 宛名 | お客様名「御中」、担当者名（品番の日報担当として登録したお客様担当者。未登録なら空欄） |
| 発行元 | 三成興業株式会社、電話・FAX・メールアドレス |
| 依頼元／担当者 | お客様名／担当者名 |
| 作業日／運搬日 | 作業日を和暦で表示（例: 令和8年10月9日（金））／運搬日は空欄（運搬は別の報告） |
| 作業場所／使用車 | マスタの名称（未選択なら空欄） |
| 現地作業時間及び作業者名 | 作業者ごとに「氏名 9時30分〜11時25分（1.92H）」、昼休憩の時間。最低10行 |
| 作業内容 | 作業内容の名称 |
| 品番／ロットNo／作業数量／不良個数／内訳 | 品番と品名、ロット、数量、不良合計、不良種別ごとの個数（不良がなければ「不具合なし」） |
| 計 | 作業数量・不良個数の合計 |
| 総時間数 | 総作業時間（作業者数×時間） |
| 運搬費 | 空欄（自動計算しないため） |
| 押印欄 | 実施先担当者／三成担当者／結果報告済欄（空欄） |
| 備考 | 入力した備考 |
| 下部 | 報告番号（第◯版）、確定日時 |

ファイル名: `日報_作業日_お客様コード_報告番号_r版.pdf`

### 運搬実績報告書

運搬日・運転者・お客様・品番ごとの数量と合計を A4 縦1枚に出力します。ファイル名: `運搬_運搬日_お客様コード_報告番号_r版.pdf`

### 共通

- PDFは確定してから数秒〜数十秒で作成されます。作成に失敗した場合は自動でやり直し、それでも失敗した場合は事務所が再出力します。
- 一度作成したPDFの様式は、後で様式を変えても作成時の様式のまま再出力します。

## 4.6 報告一覧・修正・再出力（F-06〜F-09）

| 機能 | 内容 |
|---|---|
| 一覧の絞り込み | 期間（初期値は今月）・種別（作業／運搬）・お客様・品番・状態 |
| 一覧の並び | 日付の新しい順。同じ日は登録の新しい順 |
| 一覧の項目 | 日付、種別、報告番号、お客様、品番、数量／時間、運搬回数・運搬費、状態、帳票の状態 |
| 詳細 | 報告の全項目、日報PDFのプレビュー・ダウンロード |
| 修正 | 修正理由（必須）を入力すると新しい版の下書きができ、現場と同じ入力画面で修正して確定する。確定すると新しい版の日報PDFを作成。前の版とそのPDFは残す |
| 再出力 | 再出力の理由（必須）を入力してPDFを作り直す |
| 運搬費の入力 | 確定後の運搬実績に運搬費を入力・修正。空欄で保存すると未確定に戻る。版は作らず、変更の記録を残す |
| 同時編集 | 他の人が先に更新していた場合は保存せず、再読込を求める |

## 4.7 月次集計（F-10, F-11）

### 集計の対象

- 指定した年月（1日〜末日）の、確定済みの報告（修正された報告は最新の確定版）。確定していない下書きは含めません。
- 絞り込み: お客様・品番・種別（すべて／作業／運搬）

### 集計する値

| 区分 | 値 |
|---|---|
| 作業 | 作業日報の件数、総作業個数、総不良個数、実作業時間、総作業時間（人×時間） |
| 運搬 | 運搬実績の件数、運搬数量（品番ごとの数量の合計）、運搬回数、運搬費（入力された金額の合計）、運搬費が未入力の件数 |

運搬費の按分・単価・請求金額の計算はしません。

### 表と出力

| 表 | 内容 | Excel のシート名 |
|---|---|---|
| 集計 | 対象年月・条件と、上の値の合計 | 集計 |
| 日別 | 日ごとの作業個数・不良個数・時間・運搬数量・回数・運搬費 | 日別 |
| 品番別 | 品番ごとの作業個数・不良個数・時間・運搬数量 | 品番別 |
| 作業内容別 | 品番×作業内容ごとの件数・個数・不良・時間 | 作業内容別 |
| 明細 | 報告1件ごとの日付・種別・報告番号・版・お客様・品番・作業内容・数量・不良・時間・運搬回数・運搬費 | 明細 |

- Excel は上の5シートを1ファイルで出力します。
- CSV は表ごとに出力します（Excel で文字化けしない形式）。

## 4.8 マスタ管理（F-12）

| マスタ | 主な項目 | 用途 |
|---|---|---|
| お客様 | コード、名称、締日 | 入力時の選択、日報の宛名 |
| お客様担当者 | お客様、コード、氏名、メールアドレス、日報の担当品番 | 日報の担当者欄 |
| 品番 | お客様、品番、品名、精算区分（個数／時間）、ロット必須 | 入力時の選択 |
| 作業内容 | 品番、コード、名称 | 入力時の選択 |
| 不良種別 | 品番、コード、名称、表示順 | 不良内訳の入力欄 |
| 作業者 | コード、氏名 | 作業者・報告者・運転者の選択 |
| 作業場所 | コード、名称 | 作業場所の選択 |
| 車両 | コード、名称 | 使用車・使用車両の選択 |
| 休日 | 日付、名称 | 休日の判定 |

- 使用中のデータは削除せず「無効」にします。無効にした項目は入力時の選択肢に出ませんが、過去の報告には残ります。
- 初期データは導入時に当方が登録します（お客様からの一覧のご提供が必要です）。

## 4.9 利用者管理（F-15）

| 項目 | 内容 |
|---|---|
| ログインID | 3〜100文字の英数字と . _ @ -。後から変更できない |
| 表示名 | 画面・報告に表示する名前（100文字まで） |
| 区分 | 現場／事務所／管理者／監査（複数可） |
