# 1. はじめに

## 1.1 本書の目的

本書は、三成興業株式会社様の「作業日報デジタル化システム（SANSEI 現場報告システム）」について、システムで行うこと・行わないこと、入力する項目、日報PDFの様式、月次集計の内容、完成を判定する基準を定め、お客様と当方の間で合意するための資料です。

本書で合意した内容が、以降の設計・開発・テスト・検収の基準になります。

# 2. システム化の目的と範囲

## 2.1 目的

現場で手書きしている作業結果報告書・運搬記録を iPad の入力に置き換え、次の作業を減らします。

- 手書きの日報作成と、日報のPDF化
- 事務所での手書き内容の確認・転記
- 日報から月次集計表への手作業での転記・集計

## 2.2 業務の流れ（導入後）

| 順 | 誰が | 何をする | システムの動き |
|---|---|---|---|
| 1 | 現場作業者 | 作業を始めたら iPad で作業日報を開始し、作業者が加わったとき・帰ったときに追記する（作業が終わってからまとめて入力してもよい）。全員が終わったら数量・不良を入れて確定する。運搬実績は運搬の後に入力・確定する | 作業中の日報をクラウドに保存し、どの iPad からも追記できる。確定すると日報PDFを自動で作成 |
| 2 | 現場作業者 | 日報PDFをプレビューし、iPad の共有機能でメールに添付してお客様へ送る | （メールの自動送信はしません） |
| 3 | 事務所担当者 | 報告一覧で内容を確認し、必要なら修正（新しい版）、運搬費の入力、時間外を請求するかの指定を行う | 修正すると新しい版の日報PDFを作成 |
| 4 | 事務所担当者 | 月末に月次集計を行い、Excel または CSV で出力する | 確定済みの報告を自動で集計 |
| 5 | 事務所担当者 | 出力した集計を、従来の請求用 Excel に転記して請求書を作成する | （請求計算・請求書作成はしません） |

## 2.4 システムで行わないこと（対象外）

提案書 P.3 のとおり、次の機能は今回の範囲に含みません。

- 日報メールの自動送信（担当者が従来どおり iPad からメール添付で送ります）
- 請求書・請求書鏡の自動作成、請求金額の自動計算
- 運搬費の自動按分・単価判定、請求金額への自動反映
- 時間外 1.25 倍の請求計算、複雑な請求条件マスタ（仕上げ・検査ごとの単価もこの範囲です。時間外を請求するかの指定と、仕上げ・検査ごとの数量の記録は範囲に含みます）
- 丸五ゴム様の在庫管理（F-17。ご相談中。ご判断により追加します）
- 承認ワークフロー、高機能ダッシュボード
- お客様担当者ごとのメール送信設定
- IC カード・バーコードによる入力、他システムとの連携

これらは将来のご要望に応じて別途お見積りします。

# 3. 利用者と権限

## 3.1 利用者の区分

| 区分 | 想定する利用者 | できること |
|---|---|---|
| 現場 | 現場作業者・運転手 | 作業日報・運搬実績の入力と確定、自分が登録した報告と日報PDFの表示 |
| 事務所 | 事務所担当者 | すべての報告の確認・修正・PDF再出力・運搬費の入力、月次集計と出力、マスタの参照、作業日報・運搬実績の入力（作業日報の代理入力を含む） |
| 管理者 | 事務所の責任者 | マスタの追加・修正・無効化、利用者の管理、報告の確認・PDF再出力・運搬費の入力、月次集計と出力 |
| 監査（閲覧） | 確認のみ行う方 | 報告・月次集計の参照と出力（変更はできない） |

1人の利用者に複数の区分を設定できます。事務所でマスタも管理する方は「事務所＋管理者」とします。

## 3.2 アカウント

- 導入時のアカウント（ログインIDとパスワード）は当方が作成してお渡しします。
- 運用中は、管理者が「利用者管理」画面で利用者の追加・区分の変更・利用停止・パスワード再設定・ロック解除を行えます（当方に依頼することもできます）。
- 利用者は削除せず「利用停止」にします。過去の報告は残ります。
- 利用停止・区分の変更・パスワード再設定は、その利用者がログイン中でもすぐに反映されます。
- 管理画面で設定するパスワードは12文字以上とします。5回続けて間違えると15分間ログインできなくなります。

### 自動計算と目安

| 項目 | 計算方法 |
|---|---|
| 行の実作業時間 | 終了 − 開始 − 休憩 |
| 総作業時間（総時間数） | 全従事行の実作業時間の合計 |
| 検査時間・検査外時間 | 検査区分ごとの実作業時間の合計 |
| 時間外時間 | 全従事行の「うち時間外」の合計 |
| 不良合計 | 不良内訳の個数の合計 |
| 良品数量 | 作業数量 − 不良合計（画面の参考表示） |
| 休憩の目安（表示だけ） | 行が 12:00〜13:00 と重なり休憩が0分のとき「昼の休憩が0分です」と表示。「目安を入れる」で重なりの分を入れる |
| 時間外の目安（表示だけ） | 平日17:00以降、または土日・休日マスタの日の作業のとき目安の時間を表示。「目安を入れる」で入れる |

休憩・時間外は自動では入れません（ご要望により手入力。目安を入れるかどうかは入力する方が決めます）。

例: 作業者2名がともに 9:30〜11:25（休憩0分） → 各行 1.92 時間、総作業時間 3.83 時間（提案書 P.9 と同じ値。分で計算し、表示時に時間へ換算）。
例: Aさん 8:30〜17:00（休憩60分）、Bさん 13:00〜17:00（休憩0分、途中参加） → 7.50 時間＋4.00 時間＝総作業時間 11.50 時間。

### 時間外を請求するかの指定

- 現場は従事行に「うち時間外」を入れます。事務所は確認のときに直せます（修正＝新しい版）。
- 時間外を請求するかどうかは、報告ごとに事務所が報告の詳細画面で指定します（初期値は「しない」。運搬費の入力と同じく版は作らず、変更の記録を残します）。
- 「しない」のときも、時間外の時間は記録に残ります。月次集計では、請求するものだけを「割増作業時間」として数えます。

### 作業中の日報（途中参加・途中退勤）

- 作業を開始すると、作業日報がクラウドに保存されます（作業中の日報）。現場ホームの「作業中の日報」から、**どの現場の方の iPad からも**作業者の追加・終了ができます。
- 作業日・お客様・品番などの変更と確定は、報告者本人と事務所の方が行います。
- 作業中の日報の追記は、通信できる状態で行います（通信が切れたときは時刻を控え、戻ってから入力します）。
- 誤って作った作業日報は、報告者本人と事務所の方が「破棄」できます（確定したことのないものだけ。破棄の記録は残ります）。

## 4.3 確定と報告番号

- 報告番号は、内容を初めてクラウドに保存したとき（作業日報の作業開始、または確定）に自動で付けます。作業日報は `WR-年月-連番6桁`、運搬実績は `DR-年月-連番6桁`（例: WR-202610-000001）。年月は登録した日の年月です。破棄した作業日報の番号は欠番になります。
- 確定後、現場の利用者は内容を変更できません。変更は事務所が行います（F-07）。
- 同じ確定操作を通信の再送などで二重に行っても、報告が二重に登録されないようにします。

## 4.4 下書き（F-13）

- 入力途中の内容は iPad に自動保存されます。画面を閉じても、続きから入力できます。この端末の下書きは最後の保存から24時間で消えます。ログアウトしたときも消えます。
- 作業を開始した作業日報（作業中の日報）はクラウドにも保存され、24時間で消えません。確定または破棄するまで残ります（4.1）。
- 通信が切れている間は画面上部に表示が出て、確定ボタンが押せなくなります。入力は続けられ、通信が戻れば確定できます。
